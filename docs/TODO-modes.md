# 新播放模式 TODO

現有模式：一般（單張＋10 種轉場）、輪盤（reel）、Pinterest 圖牆（wall）。
以下依建議順序排列，做完一個就打勾，並在 docs/ 補一份 `<mode>-spec.md`。

## 優先（好做、效果明顯）

- [x] **拍立得散落（polaroid）**：白框、隨機傾斜的照片一張張丟到桌面疊起來，最上面那張停留後下一張蓋上；堆到上限整疊淡出重來。純 transform，省效能。
- [x] **3D 封面流（coverflow）**：中間一張正面，兩側斜擺成 3D 透視並輪流前移。可沿用輪盤的「選中→置中」邏輯，加 perspective / rotateY。
- [x] **分割畫面／拼貼格（collage）**：2～5 格不對稱雜誌版型，每隔幾秒只換其中一格（用現有轉場），版型定期整個換掉。
- [x] **電影膠卷（filmstrip）**：帶齒孔的底片橫向連續慢速捲動，偶爾一格放大成全螢幕；可選顆粒、輕微晃動的懷舊效果。

## 中等難度（比較有記憶點）

- [x] **3D 旋轉相簿／立方體（cube / ring）**：圖片貼在立方體各面或環形旋轉木馬上緩慢旋轉，轉到正面時停頓。
- [x] **翻頁書（book）**：CSS 3D 翻頁，左右兩頁各一張圖。
- [x] **馬賽克組合（mosaic）**：先用小縮圖依色塊拼出大圖輪廓，再淡入成原圖。需預先計算每張縮圖的平均色。
- [x] **無限畫布漫遊（canvas）**：圖片散布在超大畫布上，鏡頭在圖片間平移縮放，飛到一張就停下來看。

## 氛圍／螢幕保護向

- [ ] **漂浮泡泡／星空（float）**：縮圖在 3D 空間由遠往近飄過，偶爾一張停到中間放大。
- [ ] **時間軸（timeline）**：依 EXIF 拍攝日期排成時間軸捲動，旁邊顯示年月。適合家庭相簿。
- [ ] **雙圖並排（pair）**：直式照片自動兩張並排，避免左右大片黑邊。可考慮做成「一般」模式的選項，而非獨立模式。
